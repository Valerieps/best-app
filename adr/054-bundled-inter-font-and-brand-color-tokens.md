# ADR-054: Bundled Inter font and brand color tokens

**Status:** Accepted
**Date:** 2026-10-16
**Decision:** The UI font is Inter, from the exactly pinned package `@fontsource-variable/inter` (OFL-1.1). `src/main.tsx` imports its variable-weight CSS, normal and italic; Vite copies the `.woff2` files into `dist/` with hashed names, so they are served by the app itself, cached by the service worker like any other built asset and allowed by the CSP's `default-src 'self'`. The browser downloads only the subsets whose `unicode-range` the text needs. `--font-body` keeps the system stack as a fallback while the font loads (`font-display: swap`). The brand color is a set of tokens in `tokens.css` (`--color-brand`, `-hover`, `-soft`, `-strong`); the action tokens (`--color-accent`, `--color-focus`, `--color-check`, `--color-link`) and the "Rituais" counter point to them, so no component names a hue.
**Why:** The owner chose a brand color (the projects' lilac) and Inter (spec/principios.md, "Aparência"). This amends ADR-001, which ruled out web fonts: a bundled font is a static asset with no code and no network call at run time, so it keeps `SEGURANCA.md` intact at the cost of one small dependency. Pointing the action tokens at the brand tokens keeps a future dark theme to one redefinition per token.
