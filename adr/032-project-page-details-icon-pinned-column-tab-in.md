# ADR-032: Project page details: icon, pinned column, tab in the route

**Date:** 2026-10-12
**Decision:** `Project.icon` stores an id from `PROJECT_ICONS` (domain); the drawings are inline SVG in `ui/components/Icon.tsx`, and each icon has a fixed tint from the existing tokens. Changing it records `project.iconChanged`. Whether the side column is pinned is `Settings.projectPanelPinned`, saved with `updateSettings` like the other settings, so it goes into backups. The notes tab is in the route (`#/projeto/<id>/notas`). Below 900 px the pinned column is not docked; it opens over the content from the rail. Task lines reuse the day note's `BlockLine` with `day: null`, so dates, deadline and the star behave as in the day note (spec/navegacao.md, "Do item"), instead of the draft's hover that hides the metadata. Link titles start as the domain read from the URL text, and `resource.renamed` records later changes. The progress bar is a `<progress>` element, so the UI still has no `style` attribute.
**Why:** Storing only an id keeps the backup small and lets the drawings change; reusing the existing settings and event mechanisms avoids new storage. Following the line pattern of the day note keeps one way of acting on a task across the app.
**Update (2026-10-12):** The rail was removed; the side column opens only from the button on the tabs row, which shows the number of resources. The progress bar gave way to the "Ritmo" card (ADR-033), whose bars still avoid `style` attributes.
