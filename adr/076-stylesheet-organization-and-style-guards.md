# ADR-076: Stylesheets by area, every value a token, and tests that guard both

**Status:** Accepted
**Date:** 2026-11-13
**Decision:** The global stylesheet lives under `src/ui/theme/css/` in one folder per area: `base/` (elements, buttons, inputs, motion), `layout/` (shell, sidebar, screen header, right panel), `components/` (pieces shared by several screens), `day-note/`, `closing/` ("Fechar o dia") and `screens/` (one file per screen or screen family). `global.css` imports them in a fixed order, and that order is the cascade order of the old single stylesheet. The split moved no rule: joined in import order, the files equal the old ones. Besides colors, fonts and spacing, `tokens.css` now also holds the stacking order (`--z-*`), elevation (`--shadow-*`), icon and control sizes (`--icon-size-*`, `--control-min-size`), the resize handles' width and every animation duration (`--motion-*`). The values did not change. Conditional class names go through `cx()` (`src/ui/classNames.ts`) instead of template literals. `src/ui/theme/styles.test.ts` fails the build in these cases: a stylesheet uses a color, z-index, duration or shadow literal; a stylesheet uses a custom property that is never defined; a stylesheet is missing from `global.css`; or a class selector is never used in the code (a class built as `chip--${kind}` counts when its stem is in the code).
**Why:** The files had been cut by the order they were written, so their names no longer said what they held (`sidebar.css` held the screen titles and icons, `motion-and-palette.css` held the first-use screen), and about 45 classes from removed screens were still in them. Loose z-index values and durations made layering and timing hard to change in one place. The tests keep it that way without anyone having to remember.
**Consequences:** Some areas sit in two files that are not next to each other in the import order (`closing/steps.css` and `closing/board.css`, for example), because merging them would reorder the cascade. New files go at the end of `global.css`. Moving a rule to an earlier file needs a check that no later rule of the same specificity sets the same property on the same element. Media queries cannot read custom properties, so the 640px breakpoint stays a literal. A one-off optical nudge (`margin-top: 3px` to line a checkbox up with text) also stays a literal.
