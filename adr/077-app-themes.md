# ADR-077: App themes as token blocks keyed by `data-app-theme`

**Status:** Accepted
**Date:** 2026-11-13
**Decision:** Besides the appearance (light, dark or the system's, ADR-055), the app has a theme: a palette and fonts, each with a light and a dark version. A theme is a block of token values in `tokens.css` under `:root[data-app-theme="<id>"]`, plus its two dark blocks (`@media (prefers-color-scheme: dark)` with `:root[data-app-theme="<id>"]:not([data-theme="light"])`, and `:root[data-app-theme="<id>"][data-theme="dark"]`), with the same values. The base values of `:root` are the "Clássico" theme, the look of the app before themes. What a theme changes beyond colors goes through theme hooks, tokens with the Clássico values in `:root`: `--font-display` and `--letter-spacing-display` (titles and the app's name), `--color-nav-current-bg`/`-text` (the current place in the sidebar), `--color-star` (the ★ and the logo's star), `--logo-mark-display` (whether the star shows before the name) and `--close-day-*` (the "Fechar o dia" button of the day note). The list of themes is `APP_THEMES` in `src/ui/theme/appearance.ts`, which the settings show in order; the choice is `Settings.appTheme`, absent for the default, Crepúsculo, and mirrored in `localStorage` (`best-app:app-theme`) and applied before the first render, like the appearance. `appearance.ts` always sets the attribute, the default included. The first theme, Crepúsculo, uses Bricolage Grotesque in the titles, bundled with `@fontsource-variable/bricolage-grotesque` like Inter (ADR-054).
**Why:** The owner wants the app to accept more themes, Crepúsculo first (an identity drawn from the name: Vesper is the evening star, and the day ends with "Fechar o dia"). A separate attribute keeps the theme independent of the appearance, so every theme gets both versions without a combined list. A theme's light block has the same specificity as the base dark blocks and comes later, so it would win in dark mode; each theme's dark blocks have higher specificity and must redefine every color of its light block. `tokens.test.ts` checks that for every theme, as well as identical dark blocks and readable muted text. Hooks, rather than per-theme rules in the stylesheets, keep "every value comes from tokens.css" (ADR-076) and let a new theme be a tokens-only change.
**Adding a theme:** add its id to `AppTheme` (`src/domain/entities.ts`), an entry to `APP_THEMES`, and its three blocks to `tokens.css`. A new font is bundled with a `@fontsource-variable` package imported in `src/main.tsx`.
